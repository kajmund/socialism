# Starta en simulering

När körningen är sparad kan du starta en simulering. Resultatet läggs till som ett **försök** på körningen (du kan köra igen utan att radera tidigare försök).

## Steg

1. Öppna den sparade **körningen**.
2. Starta simuleringen från körningens åtgärder.
3. Status blir att körningen **körs**. Arbetet sker som ett bakgrundsjobb.
4. Följ jobbet under **Jobb** om du vill se framsteg eller fel.
5. När status är klar: öppna **Resultat** på körningen för flöde, mätningar och jämförelser.

## Obs

- Du kan inte starta om samma körning medan den redan körs.
- Beroende på miljö kan simuleringen vara snabb (status/test) eller en längre flersagentsimulering.
- Från resultaten kan du skapa **rapporter** och ibland intervjua personas mot vad de “sett” i flödet.
