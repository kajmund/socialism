# Redigera kundens organisationsuppgifter

Varje **kund** kan ha organisationsuppgifter som experter och granskningar kan läsa när de behöver veta vem de arbetar åt. Det är skilt från din personliga profil under **Min profil**.

Ytan syns bara för **administratör** under **Verktyg** → **Kunder**.

## Steg

1. Öppna **Verktyg** → **Kunder**.
2. I tabellen, fäll ut **Organisationsuppgifter** på raden för kunden.
3. Fyll i de fält som gäller:
   - **Organisation** — företags- eller organisationsnamn
   - **Organisationsnummer**
   - **Adress**, **Adressrad 2**, **Postnummer**, **Ort**
   - **Landskod** — två bokstäver, till exempel SE
4. Välj **Spara**. Tomma fält får lämnas tomma.

## Skillnad mot användarprofil

- **Min profil** gäller dig som inloggad användare (namn, yrkesroll, profilbild).
- **Organisationsuppgifter** gäller kunden som helhet och delas av alla användare kopplade till den kunden.

Experten kan föreslå ändringar i chatten — kundändringar kräver administratörsbehörighet och godkänns via profilförslag eller direkt här.
